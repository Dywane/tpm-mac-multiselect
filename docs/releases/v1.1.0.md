# Multi-Select for Two Point Museum on macOS (arm64) — v1.1.0

Great news first: **the mod is now just a payload.** All mods share one launcher, so
updating this one never breaks the others.

**Steam Workshop:** <https://steamcommunity.com/sharedfiles/filedetails/?id=3824484305> (payload only — the loader is installed once)

## Two downloads

| Archive | What it is | How often |
|---|---|---|
| `tpm-mac-loader.zip` | launcher: injects every mod dylib it finds | install once |
| `tpm-multiselect-macos-arm64.zip` | this mod: `libtpm_ms.dylib` | replace on update |

## Install

1. Unpack the loader, e.g. `~/Applications/tpm-mac-loader`.
2. Set the game's Steam launch options to:
   ```
   "/Users/you/Applications/tpm-mac-loader/run_tpm.sh" %command%
   ```
3. Put `libtpm_ms.dylib` into `tpm-mac-loader/mods/` (or subscribe to the Workshop item —
   the loader also injects dylibs from `steamapps/workshop/content/2185060/`).

No BepInEx, no .NET runtime, no modification of the game bundle.

## Use

| Action | Result |
|---|---|
| Left Shift + drag | rectangle select |
| release | the whole group follows the cursor |
| left click | place the group |
| right click | cancel and restore the original positions |

## Requirements

Apple Silicon Mac, macOS 13+, Two Point Museum (Steam). Intel Macs are not supported.

## Notes

- Tested against game build `12.0.244870`; classes and methods are resolved by name, so small
  updates should keep working.
- Rectangle bounds come from the game's tile test, so items straddling the border can be picked up.
- Log: `/tmp/tpm_ms_native.log` (`TPM_MS_DEBUG=1` for verbose).
