# Multi-Select for Two Point Museum on macOS (arm64) — v1.0.0

Hold **Left Shift** and drag a rectangle to select many items at once, then move and rotate
them as a group.

## Install

1. Download `tpm-multiselect-macos-arm64.zip` and unpack it anywhere, e.g. `~/Applications/tpm-multiselect`.
2. Set the game's Steam launch options to:
   ```
   "/path/to/run_tpm.sh" %command%
   ```
   or launch the game with `./run_tpm.sh` from a terminal.

No BepInEx, no .NET runtime, no modification of the game bundle.

## Use

| Action | Result |
|---|---|
| Left Shift + drag | rectangle select |
| release | the group follows the cursor |
| left click | place the whole group |
| right click | cancel and restore the original positions |

## Requirements

- Apple Silicon Mac (arm64), macOS 13+
- Two Point Museum (Steam)
- Intel Macs are **not** supported

## Notes

- Tested against game build `12.0.244870`. Classes and methods are resolved by name, so small
  updates should keep working; a major rewrite would need a rebuild.
- Rectangle bounds are evaluated by the game on tile bounds, so items straddling the border can
  be included.
- Log: `/tmp/tpm_ms_native.log` (set `TPM_MS_DEBUG=1` for verbose output).

## Uninstall

Delete the folder and clear the Steam launch option. Nothing inside the game installation was
touched.
